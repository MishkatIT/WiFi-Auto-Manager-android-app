# WiFi-Auto-Manager-android-app

A production-quality, local-first Android Wi-Fi decision and automation engine built with modern Android development standards.

## Tech Stack
- **Architecture:** Clean Architecture + MVVM + Repository Pattern
- **UI:** Jetpack Compose + Material 3 Design
- **Dependency Injection:** Dagger Hilt
- **Local Persistence:** Room Database + DataStore Preferences
- **Security:** Android Keystore (EncryptedSharedPreferences)
- **Background Work:** Android WorkManager
- **Min SDK:** 26 (Android 8.0) | **Target SDK:** 35 (Android 15) | **Kotlin:** 2.0.21
